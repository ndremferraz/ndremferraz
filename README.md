## Andre Ferraz's Github Page:

Hello, I am a Graduate Student at the University of Washington in the Department of Electrical and Computer Engineering. I have a Bachelor of Science degree in Computer Engineering from The George Washington University. 

This is my Github Page, I keep all my present projects and also some old ones that I am particularly fond of. I learned a lot with this projects and I hope this may inspire some people:


## 2026
- 🤖[MyInference](https://github.com/ndremferraz/myInference)( *work in progress🚦*): An attempt to implement my own LLM inference engine in JAX hoping to learn about the modern open-source LLMs in depth and test some of the bottlenecks and important factors of distributed Inference.  
- 🤖📸🛩️[DeepVINS](https://github.com/ndremferraz/DeepVINS)( *work in progress🚦*): An attempt to develop a Visual-Inertial Navigation System based on the Transformer Model Architecture, inspired by my work with the GWU Flight Dynamics and Controls Lab. The preliminary results were very negative so I need to revamp the project.
- 🤖[distributedLLM](https://github.com/ndremferraz/distributedLLM)( *missing documenation 🚦*): Trainning a Small Language Model in style of [NanoGPT](https://github.com/karpathy/nanogpt) by Andrej Karpathy, a reference in the world of Deep Learning. The main focus of the project was to explore different distributed trainning techniques and compare them.
- ✈️🤖[ardu_ws](https://github.com/ndremferraz/ardu_ws) This is the repo containing the code that went into our Drone for the [RTX Autonomous Vehicle Competition](https://lnkd.in/p/gfCBjA68). It is very messy and hard to make sense of but I know next year's team may want to know what we did. We used ROS2 and Mavros to interact with ArduPilot. 

### 2024/2025:
- 💻🔌[LeNetCUDA](https://github.com/ndremferraz/LeNetCUDA)(*missing documentation 🚥*) This was a project I did to compare performance of a CNN model using TensorFlow and a model implemented using raw CUDA.
- 💻[MapReduce](https://github.com/ndremferraz/MapReduce) This was a assignment for a Computer Systems Engineering Class where I had to implement a multi-threaded word-frequency counter with nothing but system calls. The assignment description is in [this file](https://github.com/ndremferraz/MapReduce/blob/master/old_README.md), definitely a fun low level project. Thought me a lot about threads, shared resources and semaphores. 
- ✈️[Easter Egg Drone Project](https://github.com/ndremferraz/ECE_Drone_Project) This came from a student competition from the GW ECE department. All students were given cheap educational drones and they needed to locate easter eggs and go to them. This was my first ML project but thought me a lot about computer vision and 3D to 2D projections
- 🎮[videogame](https://github.com/ndremferraz/videogame) This was my first project here and probably the one I has the most fun building. I built a small videogame from scratch with a $4 dollar microcontroller and $30 worth of electronic components. I did everything from selecting components and designing the PCB to actually programing the individual pixels and high-level game logic.
